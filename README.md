# Transformer Normalizing Flow for Synthetic Time-Series

This repository implements a **Transformer-based Normalizing Flow** model for learning and generating synthetic time-series data.  
The project combines **affine coupling layers** with **Transformer encoders** to model complex sequential distributions.

---

## ✨ Features
- **Positional Encoding**: Adds temporal information to sequences.
- **Transformer Conditioner**: Learns scale (`s`) and shift (`t`) parameters for affine coupling.
- **Time-Wise Affine Coupling**: Alternating masking strategy for invertible transformations.
- **Normalizing Flow Model**: Stacks multiple coupling layers to approximate complex distributions.
- **Synthetic Data Generator**: Creates sawtooth-like signals with noise, trends, and frequency variations.
- **Training Loop**: End-to-end training with PyTorch, including validation loss tracking.

---

## 📂 Project Structure
- `PositionalEncoding`: Implements sinusoidal positional encoding.
- `TransformerConditioner`: Transformer encoder that outputs affine parameters.
- `TimeWiseAffineCoupling`: Affine coupling layer with parity-based masking.
- `TransformerNormalizingFlow`: Full normalizing flow model with multiple coupling layers.
- `generate_synthetic_data`: Function to generate synthetic time-series data.
- Training loop: Trains the flow model on synthetic data and evaluates validation loss.

## 🔍 Anomaly Detection
The trained normalizing flow model can also be applied to **anomaly detection** tasks:

- **Likelihood-based scoring**:  
  Since the model learns the probability distribution of normal time-series data, anomalies can be detected by computing the **log-likelihood** of new sequences.  
  - Low log-likelihood → indicates the sequence is unlikely under the learned distribution → potential anomaly.

- **Workflow**:
  1. Train the model on normal (non-anomalous) data.
  2. For each incoming sequence, compute `log_prob_x`.
  3. Define a threshold (e.g., based on validation statistics).
  4. Flag sequences below the threshold as anomalies.

- **Advantages**:
  - Works in an unsupervised setting (no need for labeled anomalies).
  - Flexible for different sequence lengths and noise levels.
  - Transformer encoder captures temporal dependencies, improving anomaly detection accuracy.

Example usage:
```python
_, log_prob = model(test_sequence)
if log_prob.item() < anomaly_threshold:
    print("Anomaly detected!")
```

---

## 📌 Notes
- The model is trained to maximize likelihood via normalizing flows.
- `log_prob_x` is computed as the sum of Gaussian log-probability and Jacobian determinant.
- Gradient clipping (`clip_grad_norm_`) is applied to stabilize training.
